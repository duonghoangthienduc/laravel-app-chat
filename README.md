# Laravel Chat Application

A modern real-time chat application built with **Laravel**, designed for fast, reliable, and scalable messaging.

## Features

- User authentication
- Private conversations
- Real-time message delivery
- Online/offline presence
- Redis-powered communication
- Clean and maintainable architecture
- Extensible for future chat and collaboration features

## Tech Stack

- Laravel
- PHP
- Redis
- MySQL/PostgreSQL
- JavaScript
- Vite
